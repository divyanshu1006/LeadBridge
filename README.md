# LeadBridge NCR — Outbound Pipeline for Recruitment Agencies

> B2B appointment setting and outbound pipeline generation designed specifically for Delhi NCR staffing and recruitment agencies.

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/divyanshu1006/LeadBridge)

---

## 🎯 About

**LeadBridge NCR** helps recruitment and staffing agencies across Delhi NCR (Noida, Gurgaon, Faridabad, Greater Noida, Manesar, Ghaziabad) start conversations with companies actively hiring in their vertical. 

Instead of waiting for word-of-mouth or fighting on job boards, LeadBridge NCR builds a targeted, proactive outbound engine that places qualified hiring-company meetings directly onto your calendar.

## 🛠️ Tech Stack

- **Framework:** [Next.js 16](https://nextjs.org/) (App Router + Turbopack)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Form Handling:** [React Hook Form](https://react-hook-form.com/) + [Zod](https://zod.dev/)
- **Hosting:** [Vercel](https://vercel.com/) (100% Free Tier)

## 🌐 Pages & Structure

- **Home (`/`)**: High-converting credibility hero with single CTA (`[Book a 10-minute conversation]`), PAS problem breakdown, "Why Outbound Works" framework, 3-pillar solution overview, 4-step execution timeline, 8 recruitment verticals, honest pilot-first FAQ, and trust guarantee.
- **Services (`/services`)**: In-depth breakdown of the 4 core pillars: Hiring-Company Research, Professional Multi-Channel Outreach, Reply Qualification, and Meeting Booking with Pre-Call Briefing.
- **How It Works (`/how-it-works`)**: Transparent 4-step roadmap (Day 1 Alignment to Day 8+ Launch) and execution speed breakdown.
- **About Us (`/about`)**: Agency purpose, mission, core values, and candid early-stage pilot disclosure.
- **Contact (`/contact`)**: Form and direct communication channels.

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/divyanshu1006/LeadBridge.git
cd LeadBridge

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
